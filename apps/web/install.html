Install Sayvox for Windows

Windows 10 or 11, 64-bit. Install once; Sayvox updates itself after that.

Download for Windows (.exe) .msi for IT-managed PCs

“Windows protected your PC”

Sayvox's installer isn't code-signed yet, so Windows SmartScreen warns about it the first time. That's expected. Updates after installing are signed and checked by Sayvox itself, so they can't be tampered with.

  1. Open the downloaded Sayvox-setup.exe.
  2. On the blue Windows protected your PC screen, click More info. (It's a small link under the message.)
  3. Check that it says App: Sayvox-setup.exe (or Sayvox_x.y.z_x64-setup.exe), then click Run anyway.
  4. If Windows asks Do you want to allow this app to make changes, click Yes.
  5. Follow the installer. Sayvox opens and asks you to sign in.

Windows 11 with Smart App Control on may block unsigned apps outright, with no Run anyway button. Turning Smart App Control off can be hard to undo, so we don't ask you to change it.

Some antivirus tools flag new unsigned apps. If yours quarantines Sayvox, check the download (below) and restore it from quarantine.

Check the download (optional)

Compare the file's SHA-256 checksum with the one we publish. In PowerShell, in your Downloads folder: 

Get-FileHash .\Sayvox-setup.exe -Algorithm SHA256

The Hash must match the line for Sayvox-setup.exe in SHA256SUMS.txt (capitals don't matter). If it doesn't, delete the file and don't run it.

After installing

  • Sayvox lives in the system tray. Click its icon for settings.
  • Hold Ctrl + Shift, speak, and let go. Your words appear where your cursor is. You can change the hotkey in Settings → General.
  • If dictation says the microphone is off, turn on Let desktop apps access your microphone in Windows Settings → Privacy & security → Microphone.
  • To uninstall: Windows Settings → Apps → Installed apps → Sayvox → Uninstall. To delete your account too, do that in Sayvox first (Settings → Privacy & Account).
