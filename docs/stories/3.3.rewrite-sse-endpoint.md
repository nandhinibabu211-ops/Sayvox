# Story 3.3: `POST /v1/rewrite` SSE endpoint

## Status
Draft

## Story
**As a** user,
**I want** the rewrite streamed back as it is generated,
**so that** I see progress immediately and the text lands as soon as it's done.

## Acceptance Criteria
1. Validates `RewriteRequest`; the session must belong to the user and be `started`.
2. Builds messages: system template; user `<target_app>…</target_app>\n<transcript>…</transcript>`.
3. Streams SSE events `meta`, `token`, `fallback`, `done`, `error`.
4. Transcript is never logged; pino redaction is verified by a test.
5. Client disconnect aborts the upstream request.

## Tasks / Subtasks
- [ ] `apps/api/src/modules/rewrite/route.ts`: Zod validation, ownership + status check (`404`/`409`) (AC 1)
- [ ] Resolve preset from settings cache; `buildMessages()` from `packages/prompts` (AC 2)
- [ ] SSE writer on `reply.raw`: headers `text/event-stream`, `no-store`; `: ping` heartbeat every 5 s; exactly one terminal event (AC 3)
- [ ] Map OpenRouter client signals → `fallback` / `token` / `done` / `error` per `contracts/rewrite-sse.md` (AC 3)
- [ ] On `done`: update session (`model_used`, `fallback_used`, tokens, ttft, total) and add `llm_cost_usd` to `usage_daily` (AC 3)
- [ ] `request.raw.on("close")` → abort controller (AC 5)
- [ ] pino `redact` for `req.body`, `transcript`, `threadContext`; Error Reporting calls never include bodies (AC 4)
- [ ] Contract test `apps/api/test/contract/rewrite.test.ts`; redaction test `apps/api/test/unit/redaction.test.ts` (AC 3, 4)
