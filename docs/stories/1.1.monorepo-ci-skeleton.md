# Story 1.1: Monorepo and CI skeleton

## Status
Draft

## Story
**As a** developer,
**I want** a monorepo with desktop, api and shared packages and CI,
**so that** every later story has a consistent home and automated checks.

## Acceptance Criteria
1. pnpm workspace + Turborepo with `apps/desktop`, `apps/api`, `apps/web`, `packages/shared`, `packages/prompts`, `eval/`.
2. Lint (ESLint + Prettier, clippy + rustfmt) and typecheck run with one command.
3. GitHub Actions runs lint, typecheck and unit tests on every PR.
4. `apps/api` exposes `GET /healthz` returning `200 {"status":"ok"}`.
5. README documents local setup.

## Tasks / Subtasks
- [ ] Init repo, `pnpm-workspace.yaml`, `turbo.json`, root `package.json` scripts `lint`, `typecheck`, `test`, `dev` (AC 1, 2)
- [ ] Scaffold `apps/desktop` with `create-tauri-app` (Tauri v2, Vite, TypeScript) (AC 1)
- [ ] Scaffold `apps/api` Fastify 5 + TypeScript, `src/server.ts`, `GET /healthz` + Vitest test (AC 4)
- [ ] Create `packages/shared` (Zod schemas, types) and `packages/prompts` (empty templates export) (AC 1)
- [ ] Shared ESLint/Prettier config; `cargo clippy -D warnings` + `cargo fmt --check` in desktop (AC 2)
- [ ] `.github/workflows/ci.yml`: pnpm install cache, Rust toolchain, run `pnpm lint typecheck test` (AC 3)
- [ ] README: prerequisites (Node 22, pnpm, Rust stable, Tauri deps), `pnpm dev` (AC 5)
