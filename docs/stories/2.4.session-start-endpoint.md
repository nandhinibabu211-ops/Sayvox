# Story 2.4: `POST /v1/session/start`

## Status
Draft

## Story
**As a** user,
**I want** recording to start instantly when I press the hotkey,
**so that** my first words are always captured.

## Acceptance Criteria
1. Auth → quota check → insert `sessions` row (`status=started`) → mint Scribe single-use token → return `SessionStartResponse` incl. keyterms and language hint.
2. p95 < 150 ms excluding ElevenLabs latency is measured; including the provider call, p95 < 250 ms in staging.
3. Client token cache pre-fetches one session after each use and on app start.
4. Unused pre-fetched sessions older than the token TTL are marked `abandoned` by a sweeper.
5. The dev-only endpoint from Story 1.5 is removed.

## Tasks / Subtasks
- [ ] `apps/api/src/modules/session/start.ts`: handler with Zod schema from `packages/shared` (AC 1)
- [ ] Run token mint and session insert concurrently (`Promise.all`) after the quota check (AC 1, 2)
- [ ] Keyterms + language hint from `settings:{userId}` cache (fallback to DB) (AC 1)
- [ ] Return `expiresAt` from the token TTL (R1) (AC 1, 3)
- [ ] OTel histogram `session_start_ms` with and without provider span (AC 2)
- [ ] `apps/desktop/src/services/tokenCache.ts`: hold one prefetched session; refresh after use, on expiry and on app start/wake (AC 3)
- [ ] `apps/api/src/modules/session/sweeper.ts`: every minute mark `started` sessions past TTL with no end as `abandoned` (AC 4)
- [ ] Delete `apps/api/src/modules/dev/scribeToken.ts` and its client call (AC 5)
- [ ] Contract test `apps/api/test/contract/session-start.test.ts` (quota exceeded, rate limited, kill switch, client outdated) (AC 1)
