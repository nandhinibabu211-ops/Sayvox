# Story 5.5: Free-tier caps (ADR-004)

## Status
Draft

## Story
**As the** business,
**we want** a free tier with a daily audio cap and limited presets,
**so that** users can try Sayvox without unbounded cost.

## Acceptance Criteria
1. Free plan daily cap and allowed presets are decided and recorded.
2. Enforced server-side and shown in the Usage screen.

## Tasks / Subtasks
- [ ] Analyse beta usage (minutes/day distribution) and cost model (architecture cost table) (AC 1)
- [ ] Initial values already set in `docs/adr/ADR-004-free-tier.md` (10 min/day, 120 min/month, Balanced + Cheapest, 25 terms); update the ADR if beta data says otherwise (AC 1)
- [ ] Update seed/migration for `free` plan values (AC 1)
- [ ] Confirm enforcement via Story 2.3 limits and Story 2.6 preset lock; Usage screen copy (AC 2)

## Dev Notes
