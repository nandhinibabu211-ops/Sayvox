# Story 6.7: Load test

## Status
Draft

## Story
**As the** operator,
**I want** the system load-tested at 3× expected peak,
**so that** launch day traffic doesn't break latency targets.

## Acceptance Criteria
1. k6 scenario simulates 3× expected peak simultaneous sessions against staging (`/session/start`, `/rewrite` with mocked or capped providers).
2. p95 targets and error rate < 1 % hold; report saved to `eval/results/load-<date>.md`.

## Tasks / Subtasks
- [ ] `eval/load/session-flow.js`: start → rewrite (SSE until done) → end, with think time (AC 1)
- [ ] Staging flag to route ElevenLabs token mint and OpenRouter to latency-realistic mocks (AC 1)
- [ ] Small real-provider run within spend caps to validate provider limits (AC 1)
- [ ] Observe autoscaling, Postgres write rate, Redis latency; tune instance counts/pool sizes (AC 2)
- [ ] Write report with results and follow-ups (AC 2)
