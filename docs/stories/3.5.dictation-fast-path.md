# Story 3.5: Dictation fast path

## Status
Draft

## Story
**As a** user,
**I want** plain dictation to skip the slow parts,
**so that** text appears in under a second.

## Acceptance Criteria
1. Dictation mode uses local rule-based cleanup (fillers, spacing, capitalisation) and optionally a minimal LLM pass behind a setting flag.
2. Release → inserted p95 < 1 s is maintained.

## Tasks / Subtasks
- [ ] `apps/desktop/src/services/cleanup.ts`: remove standalone fillers (um, uh, erm, "you know", filler "like"), collapse whitespace, sentence-case, ensure terminal punctuation (AC 1)
- [ ] Self-correction rules for common patterns ("X no wait Y", "X sorry I mean Y", "X actually Y") with conservative matching (AC 1)
- [ ] Preserve dictionary terms' exact casing (AC 1)
- [ ] Setting `dictationLlmPass` (default off) → calls `/v1/rewrite` with `mode=dictation` using the minimal template (AC 1)
- [ ] Timing harness re-run (Story 1.8) to confirm p95 < 1 s (AC 2)
- [ ] Unit tests `cleanup.test.ts` with Indian English examples ("na", "only" usages must not be stripped) (AC 1)

## Dev Notes
- Scribe output already includes punctuation; rules should be light to avoid damaging it.
- Session `model_used` stays null on the local path.

### Testing
