# Story 3.6: Streaming overlay and review-before-insert

## Status
Draft

## Story
**As a** user,
**I want** to watch the rewrite appear and optionally approve it before it's inserted,
**so that** I stay in control of what gets typed.

## Acceptance Criteria
1. Tokens render into the overlay as they arrive without layout jump.
2. `insert_mode=review`: waits for Enter (insert) / Esc (discard); keys are captured only while the overlay is in review state.
3. `insert_mode=auto`: inserts on `done`.

## Tasks / Subtasks
- [ ] `apps/desktop/src/services/rewriteClient.ts`: `fetch` + ReadableStream SSE parser; timers for TTFT and total (AC 1)
- [ ] Overlay Rewriting view: fixed width, grows downward to max height then scrolls; batch token renders per animation frame (AC 1)
- [ ] Review state: register temporary Enter/Esc global handlers in Rust only while in review; release them on exit (AC 2)
- [ ] Review shows hint "Enter to insert · Esc to discard"; timeout 60 s → discard (AC 2)
- [ ] Auto mode inserts on `done` (AC 3)
- [ ] Session end reports `discarded` when Esc (AC 2)
- [ ] Component tests for state transitions per `docs/front-end-spec.md` §3.2 (AC 1–3)

## Dev Notes
- Overlay must never take focus; Enter/Esc must not reach the target app while in review (consume events in the hook).
- Respect reduced-motion setting.

### Testing
- Component tests; manual check that Enter doesn't send a Slack message while reviewing.
