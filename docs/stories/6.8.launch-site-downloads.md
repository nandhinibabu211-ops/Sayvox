# Story 6.8: Launch site and downloads

## Status
Draft

## Story
**As a** prospective user,
**I want** a clear website to learn about Sayvox and download it,
**so that** I can get started in minutes.

## Acceptance Criteria
1. Landing page with download buttons (OS-detected), pricing, privacy and terms.
2. Installers served from CDN with checksums.

## Tasks / Subtasks
- [ ] `apps/web`: landing (hero demo, how it works, modes), pricing from plans config, privacy, terms (AC 1)
- [ ] Windows download buttons (`.exe` primary, `.msi` secondary); non-Windows visitors see a "Windows only" note (AC 1)
- [ ] Download links point to the latest release on Cloud Storage + Cloud CDN; checksums displayed; link to the install guide for the unsigned-installer prompts (AC 2)
- [ ] Deploy to Firebase Hosting; Lighthouse ≥ 90 performance and accessibility (AC 1)

## Dev Notes
- Hosting: architecture §2 (landing site + downloads).

### Testing
- Manual on Windows browsers (Chrome, Edge); link check in CI.
