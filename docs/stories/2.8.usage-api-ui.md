# Story 2.8: Usage API and UI

## Status
Draft

## Story
**As a** user,
**I want** to see how many minutes I've used and my limits,
**so that** I'm never surprised by a cap.

## Acceptance Criteria
1. `GET /v1/usage` returns today's and this period's minutes used, limits and reset times.
2. Usage & Plan screen shows progress bars.

## Tasks / Subtasks
- [ ] `apps/api/src/modules/usage/get.ts`: read Redis counters (fallback `usage_daily` sum), plan limits, `dailyResetAt` (next UTC midnight), `periodResetAt` (subscription `current_period_end` or month start) (AC 1)
- [ ] Response matches `Usage` schema in `contracts/openapi.yaml` (AC 1)
- [ ] `apps/desktop/src/settings/Usage.tsx`: two ProgressBars, plan name, Upgrade button placeholder (wired in Story 6.2) (AC 2)
- [ ] Refresh on screen open and after each session end (AC 2)
- [ ] Contract test (AC 1)

## Dev Notes
- Display minutes rounded to one decimal; compute from seconds server-side.

### Testing
- Contract test with seeded usage rows; component test for 0 %, 80 % (warning colour), 100 %.
