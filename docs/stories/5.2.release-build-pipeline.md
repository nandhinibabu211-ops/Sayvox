# Story 5.2: Release build pipeline (no paid signing)

## Status
Draft

## Story
**As a** user,
**I want** installers I can verify and install with clear steps,
**so that** I can get Sayvox running even though the builds aren't certificate-signed.

## Acceptance Criteria
1. On a version tag, CI builds unsigned Windows `.msi` and NSIS `.exe` installers (ADR-007, ADR-010).
2. Artifacts and SHA-256 checksums are uploaded to Cloud Storage.
3. The install guide documents the Windows SmartScreen "More info → Run anyway" step.

## Tasks / Subtasks
- [ ] `.github/workflows/release.yml` on `v*` tags, `windows-latest` runner (AC 1)
- [ ] Build `.msi` and NSIS `.exe` without signing; `x86_64-pc-windows-msvc` target (AC 1)
- [ ] Generate `SHA256SUMS.txt`; upload installers + checksums to the Cloud Storage release bucket via Workload Identity Federation (AC 2)
- [ ] Install guide page with screenshots for Windows 10 and 11, including how to check the checksum with `Get-FileHash` (AC 3)

## Dev Notes
- ADR-007: no Windows certificate (no free option for closed-source apps). ADR-010: Windows only.
- Update packages are still signed with the Tauri updater key (Story 5.3), so updates can't be tampered with.
- Some antivirus tools may flag unsigned installers; track reports during beta.

### Testing
- Install on clean Windows 10 and Windows 11 VMs following only the install guide.
