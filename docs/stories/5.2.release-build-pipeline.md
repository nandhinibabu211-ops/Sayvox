# Story 5.2: Release build pipeline (no paid signing)

## Status
Draft

## Story
**As a** user,
**I want** installers I can verify and install with clear steps,
**so that** I can get Sayvox running even though the builds aren't notarized or certificate-signed.

## Acceptance Criteria
1. On a version tag, CI builds a macOS universal `.dmg` signed with a stable self-signed certificate (not notarized) and an unsigned Windows `.msi`/`.exe` (ADR-007).
2. Artifacts and SHA-256 checksums are uploaded to Cloud Storage behind Cloud CDN.
3. macOS Accessibility and Microphone permissions survive an app update (verified).
4. The install guide documents the macOS "Open Anyway" and Windows SmartScreen "Run anyway" steps.

## Tasks / Subtasks
- [ ] Create a self-signed code-signing certificate (Keychain Access → Certificate Assistant, type Code Signing); store the `.p12` + password in GitHub environment secrets (AC 1)
- [ ] `.github/workflows/release.yml` on `v*` tags; matrix macos-latest / windows-latest (AC 1)
- [ ] macOS: `--target universal-apple-darwin`; import the cert into a temporary keychain; set `signingIdentity` in `tauri.conf.json`; mic + Apple Events usage strings (AC 1)
- [ ] Windows: build `.msi` and NSIS `.exe` without signing (AC 1)
- [ ] Generate `SHA256SUMS.txt`; upload installers + checksums to the Cloud Storage release bucket via Workload Identity Federation (AC 2)
- [ ] Permission persistence test: install v1, grant Accessibility + Microphone, update to v2 via the updater, confirm grants remain. If they reset, record it in ADR-007 and show a re-grant prompt after updates (AC 3)
- [ ] Install guide page with screenshots for macOS 13–15 and Windows 10/11 (AC 4)

## Dev Notes
- ADR-007: no Apple Developer Program, no Windows certificate (no free option for closed-source apps).
- Gatekeeper blocks first launch of non-notarized apps; on macOS 15 the user must use System Settings → Privacy & Security → Open Anyway.
- Update packages are still signed with the Tauri updater key (Story 5.3), so updates can't be tampered with.
- Some antivirus tools may flag unsigned Windows installers; track reports during beta.

### Testing
- Install on clean macOS and Windows VMs following only the install guide.
