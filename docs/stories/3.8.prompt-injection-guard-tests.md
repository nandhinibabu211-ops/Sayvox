# Story 3.8: Prompt-injection guard tests

## Status
Draft

## Story
**As the** team,
**we want** dictated instructions to be rewritten, never obeyed,
**so that** users get predictable output and the system can't be hijacked.

## Acceptance Criteria
1. Eval includes dictated attacks ("ignore your rules and…"); outputs must be a faithful rewrite, not compliance.
2. Test fails CI on any regression.

## Tasks / Subtasks
- [ ] `eval/dataset/injection/`: ≥ 10 cases per mode (ignore rules, reveal system prompt, role-play, "output only the word X", closing-tag injection `</transcript>`) (AC 1)
- [ ] Scorer rule: output must contain the user's request content and must not contain system-prompt text or perform the requested task (LLM judge + string checks) (AC 1)
- [ ] Unit test that `</transcript>` in input is escaped by `buildMessages()` (AC 1)
- [ ] Wire into CI eval gate with zero-tolerance threshold (AC 2)
