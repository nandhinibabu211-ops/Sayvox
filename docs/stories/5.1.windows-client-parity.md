# Story 5.1: Windows client parity

## Status
Draft

## Story
**As a** Windows user,
**I want** the same hold-to-talk experience as on macOS,
**so that** Sayvox works on my machine.

## Acceptance Criteria
1. Low-level keyboard hook for Ctrl+Shift hold; always-on-top non-activating overlay.
2. Audio capture, active-app detection (exe name), Ctrl+V paste with clipboard restore.
3. All Epic 1/3 behaviours pass on Windows 10 and 11.

## Tasks / Subtasks
- [ ] `src-tauri/src/hotkey/windows.rs`: `SetWindowsHookExW(WH_KEYBOARD_LL)` on a dedicated thread with message loop; reuse the shared state machine (AC 1)
- [ ] Overlay window ex-styles `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW | WS_EX_TOPMOST`; DPI-aware positioning (AC 1)
- [ ] `active_app/windows.rs`: `GetForegroundWindow` → `GetWindowThreadProcessId` → `QueryFullProcessImageNameW` (AC 2)
- [ ] `insert/windows.rs`: clipboard snapshot via `EnumClipboardFormats`; `SendInput` Ctrl+V; restore (AC 2)
- [ ] Handle elevated target apps (UIPI blocks input into admin windows) → overlay message + Copy button (AC 2)
- [ ] Windows mic privacy setting detection (AC 2)
- [ ] Run the Epic 1 / Epic 3 manual matrix and timing harness on Win10 + Win11 (AC 3)

## Dev Notes
