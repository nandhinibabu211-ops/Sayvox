# Story 4.5: CI quality gate

## Status
Draft

## Story
**As the** team,
**we want** prompt and model changes blocked when quality regresses,
**so that** no release makes output worse.

## Acceptance Criteria
1. PRs touching `packages/prompts` or preset config run the eval; merge is blocked on regression beyond threshold.
2. Results are posted as a PR summary.

## Tasks / Subtasks
- [ ] `.github/workflows/eval.yml` with `paths:` filter for `packages/prompts/**`, `apps/api/src/modules/config/presets.ts` (AC 1)
- [ ] Compare against last `main` result stored as artifact; threshold: no mode loses > 1 case net, zero injection failures (AC 1)
- [ ] Required status check in branch protection (AC 1)
- [ ] Job summary with per-mode table and links to result JSON (AC 2)
- [ ] Use staging keys from GitHub secrets with spend caps (AC 1)
