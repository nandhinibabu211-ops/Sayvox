# Story 1.5: Dev-only Scribe token endpoint

## Status
Draft

## Story
**As a** developer,
**I want** a dev endpoint that mints a single-use Scribe token,
**so that** the PoC client never holds the ElevenLabs key.

## Acceptance Criteria
1. `POST /v1/dev/scribe-token` (registered only when `NODE_ENV=development`) calls the ElevenLabs single-use token API and returns `{ token }`.
2. `ELEVENLABS_API_KEY` is read only server-side.
3. Endpoint path, model id and message names are verified against current ElevenLabs docs and recorded in `specs/001-voice-to-prompt-mvp/research.md` (R1).

## Tasks / Subtasks
- [ ] Verify in the ElevenLabs API reference: token endpoint, token TTL, Scribe v3 Live `model_id`, WS URL params, message names, keyterm and language params; update `research.md` R1 and `contracts/scribe-realtime.md` (AC 3)
- [ ] `apps/api/src/lib/elevenlabs/token.ts`: `mintScribeToken()` via undici, 2 s timeout (AC 1, 2)
- [ ] `apps/api/src/modules/dev/scribeToken.ts`: route registered only when `env.NODE_ENV === "development"` (AC 1)
- [ ] Zod env schema: `ELEVENLABS_API_KEY` required in api only (AC 2)
- [ ] Unit test with mocked fetch; test that the route is absent in production mode (AC 1)
- [ ] CI check: fail if `ELEVENLABS_API_KEY` or `xi-api-key` appears under `apps/desktop/` (AC 2)
