# Story 5.7: Account deletion

## Status
Draft

## Story
**As a** user,
**I want** to delete my account and all my data,
**so that** I stay in control of my information.

## Acceptance Criteria
1. `DELETE /v1/account` removes user, settings, dictionary terms, sessions and usage rows, cancels any subscription, and deletes the auth identity.
2. UI with typed confirmation; signs out locally and clears the keychain.

## Tasks / Subtasks
- [ ] `apps/api/src/modules/account/delete.ts`: cancel Razorpay subscription (if any) → delete Identity Platform user via Firebase Admin SDK → `DELETE FROM users` (cascade) → purge Redis keys `*:{userId}*` (AC 1)
- [ ] Idempotent and resumable if a step fails (retry job) (AC 1)
- [ ] Privacy & Account screen: Delete button → modal requiring typing "DELETE" (AC 2)
- [ ] Client: clear keychain, local settings, pending session-end queue; return to onboarding (AC 2)
- [ ] Integration test asserting zero rows remain for the user in every table (AC 1)
