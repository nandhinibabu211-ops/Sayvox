# Story 4.1: Transcript test set

## Status
Draft

## Story
**As the** team,
**we want** a fixed set of real dictations with a Lemon baseline,
**so that** quality claims are measurable and repeatable.

## Acceptance Criteria
1. `eval/dataset/` holds 30+ real dictations (audio + reference transcript + expected-output notes), incl. Indian English, Hinglish, names/jargon ("Zoho", "Zia"), self-corrections and injection attempts.
2. Consent is recorded for every contributed sample; no customer data.
3. Lemon outputs are captured for the same phrases as a baseline.

## Tasks / Subtasks
- [ ] Define case schema `eval/dataset/schema.json`: id, mode, targetApp, audio path, reference transcript, required facts, forbidden content, notes (AC 1)
- [ ] Record ≥ 30 cases: ≥ 10 dictation, ≥ 10 prompt, ≥ 5 email/slack, plus injection suite from Story 3.8; ≥ 40 % Indian English / Hinglish speakers (AC 1)
- [ ] Consent form + `eval/dataset/CONSENT.md` log (contributor id, date, scope) (AC 2)
- [ ] Capture Lemon output per case with date/version in `eval/baselines/lemon/` (AC 3)
- [ ] Store audio with Git LFS (AC 1)

## Dev Notes
- This is the only place real speech text is stored, and it's consented test data — never production data (Constitution I).
