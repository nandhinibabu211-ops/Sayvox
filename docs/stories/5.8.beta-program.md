# Story 5.8: Beta program

## Status
Draft

## Story
**As the** team,
**we want** a managed private beta with 50+ users,
**so that** we validate stability and latency before launch.

## Acceptance Criteria
1. Invite-only allowlist; feedback channel; weekly metrics review against the gate (50+ users for two weeks, crash-free sessions > 99.5 %, no p95 regressions).

## Tasks / Subtasks
- [ ] `beta_allowlist` check at sign-in (email list in config/DB) (AC 1)
- [ ] In-app "Send feedback" (opens form; no automatic transcript attachment) (AC 1)
- [ ] Recruit ≥ 50 users, with Indian English speakers and both Windows 10 and 11 represented (AC 1)
- [ ] Weekly review doc template `docs/beta/weekly-review.md` (crash-free %, p50/p95 per mode, fallback rate, top feedback) (AC 1)
- [ ] Gate decision record at end of two weeks (AC 1)
