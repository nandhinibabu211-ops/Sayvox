# Story 1.4: Microphone capture at 16 kHz PCM

## Status
Draft

## Story
**As a** user,
**I want** my voice captured cleanly the moment I press the hotkey,
**so that** transcription is accurate and no first words are lost.

## Acceptance Criteria
1. `audio` module captures the default input device via `cpal` and resamples to 16 kHz mono 16-bit PCM.
2. Emits chunks of 100–250 ms (configurable, default 160 ms).
3. Keeps a ring buffer of the current utterance (for Scribe retry, Story 3.7).
4. Requests microphone permission on first use; denial surfaces an error state.
5. Resampler has unit tests (48 kHz and 44.1 kHz inputs).

## Tasks / Subtasks
- [ ] `src-tauri/src/audio/capture.rs`: open default input stream with `cpal`; downmix to mono (AC 1)
- [ ] `src-tauri/src/audio/resample.rs`: resample to 16 kHz (e.g. `rubato`), convert f32 → i16 with clipping (AC 1, 5)
- [ ] `src-tauri/src/audio/chunker.rs`: emit fixed-size frames (`chunk_ms * 16` samples); flush remainder on stop (AC 2)
- [ ] `src-tauri/src/audio/ring.rs`: bounded buffer sized for `maxSessionSeconds` (300 s ≈ 9.6 MB); zeroed after each session (AC 3)
- [ ] Keep the input stream warm (paused) from app start so capture begins < 20 ms after press
- [ ] Send chunks to the TS layer via a Tauri `ipc::Channel` (binary), not JSON events
- [ ] Detect Windows "Let apps access your microphone" off (capture fails with access denied) and show the guide (AC 4)
- [ ] Permission denied / device lost → `audio://error` with code → overlay Error state (AC 4)
- [ ] Unit tests: 48 kHz sine keeps frequency at 16 kHz; 44.1 kHz input; stereo downmix; chunk sizes (AC 5)

## Dev Notes
- Scribe audio format: 16 kHz, mono, 16-bit PCM LE — `specs/001-voice-to-prompt-mvp/contracts/scribe-realtime.md`.
- Audio never goes to the Sayvox backend and is never logged or persisted (Constitution I, II).
- Mic device picker arrives in Story 2.6; read a preferred device id from settings if present, else use default.

### Testing
- `cargo test -p sayvox-desktop audio::`
- Manual: built-in mic, USB headset, Bluetooth headset (HFP 8/16 kHz devices).
