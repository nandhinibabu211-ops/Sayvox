# Story 6.1: Razorpay integration (ADR-003)

## Status
Draft

## Story
**As a** developer,
**I want** a single Razorpay billing module,
**so that** users can subscribe to paid plans.

## Acceptance Criteria
1. `razorpay` billing module: Razorpay Plans mapped to Sayvox plans, subscription creation and cancellation.
2. Razorpay test mode is used in dev and staging; live keys exist only in prod Secret Manager.

## Tasks / Subtasks
- [ ] Create Razorpay Plans (test mode) for each paid Sayvox plan; store plan ids in config, keyed by `plans.id` (AC 1)
- [ ] `apps/api/src/modules/billing/razorpay.ts`: `createSubscription(user, planId)`, `cancelSubscription(subId)` using the Razorpay Node SDK (AC 1)
- [ ] Store `RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET`, `RAZORPAY_WEBHOOK_SECRET` in Secret Manager per environment (AC 2)
- [ ] Unit tests with SDK mocks (AC 1)

## Dev Notes
- ADR-003: Razorpay only; Stripe dropped. Non-INR cards need Razorpay international payments enabled on the account (owner action).
- Prices in INR from `plans`; no prices hard-coded in the client.

### Testing
- Unit tests; Razorpay test mode only outside prod.
