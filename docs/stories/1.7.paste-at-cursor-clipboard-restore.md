# Story 1.7: Paste at cursor with clipboard restore

## Status
Draft

## Story
**As a** user,
**I want** the text typed where my cursor is without losing what I had copied,
**so that** dictation fits seamlessly into my work.

## Acceptance Criteria
1. `insert` saves clipboard contents (text and, where possible, other formats), writes the result, sends Ctrl+V via `SendInput`, and restores the clipboard in a `finally` path.
2. If paste is blocked (e.g. elevated/admin target window), the text stays in the overlay with a Copy button.
3. Works in Notepad, Word, Chrome/Edge text fields, Slack desktop and VS Code/Cursor.
4. Clipboard is restored even if paste fails.

## Tasks / Subtasks
- [ ] `src-tauri/src/insert/clipboard.rs`: snapshot all available formats via `EnumClipboardFormats` (AC 1)
- [ ] `src-tauri/src/insert/paste.rs`: write text, confirm pasteboard change, synthesize Ctrl+V via `SendInput` (AC 1)
- [ ] Restore the snapshot after ~150 ms (configurable) via a guard with `Drop` so it runs on every path (AC 1, 4)
- [ ] Clear held modifier state before synthesizing paste (user may still hold Shift)
- [ ] Detect UIPI/elevation block (target process integrity level above ours) before pasting (AC 2)
- [ ] If paste can't run, keep text in the overlay with a "Copy" button (spec edge case)
- [ ] Manual test matrix in `docs/qa/insert-matrix.md` (AC 3)
