# Story 1.7: Paste at cursor with clipboard restore

## Status
Draft

## Story
**As a** user,
**I want** the text typed where my cursor is without losing what I had copied,
**so that** dictation fits seamlessly into my work.

## Acceptance Criteria
1. `insert` saves clipboard contents (text and, where possible, other formats), writes the result, sends Cmd+V (macOS) / Ctrl+V (Windows), and restores the clipboard in a `finally` path.
2. macOS Accessibility permission is checked; if missing, the onboarding guide is shown.
3. Works in TextEdit, Notes, Chrome text fields, Slack desktop and VS Code/Cursor.
4. Clipboard is restored even if paste fails.

## Tasks / Subtasks
- [ ] `src-tauri/src/insert/clipboard.rs`: snapshot all available formats (macOS `NSPasteboard` items; Windows `EnumClipboardFormats`) (AC 1)
- [ ] `src-tauri/src/insert/paste.rs`: write text, confirm pasteboard change, synthesize Cmd/Ctrl+V via `CGEventPost` / `SendInput` (AC 1)
- [ ] Restore the snapshot after ~150 ms (configurable) via a guard with `Drop` so it runs on every path (AC 1, 4)
- [ ] Clear held modifier state before synthesizing paste (user may still hold Shift)
- [ ] `AXIsProcessTrustedWithOptions` check exposed as Tauri command `permissions_status()` (AC 2)
- [ ] If paste can't run, keep text in the overlay with a "Copy" button (spec edge case)
- [ ] Manual test matrix in `docs/qa/insert-matrix.md` (AC 3)
